# Nea Gentiles — CV & Portfolio

A responsive personal CV and portfolio website for showcasing Nea's education, skills, projects, achievements, experience, and contact information.

## Features

- Responsive layout for desktop and mobile
- Light and dark themes
- Mobile navigation menu
- Animated role text and scroll-reveal effects
- Project cards with category filters
- Contact form that opens the visitor's default email app
- Back-to-top button and scroll progress indicator

## Built with

- HTML
- CSS
- JavaScript

## Project files

- `index1.html` — website content (rename this to `index.html` for GitHub Pages)
- `style1.css` — styling and responsive layout
- `script1.js` — interactive features
- `tarantado.jpg` — profile photo used on the home section

## Run locally

Keep the HTML, CSS, JavaScript, and profile photo files together in the same folder. Open `index1.html` in a web browser to view the site.

If your HTML file is still named `index1.html`, rename it to `index.html` so it opens automatically when hosted.

## Deploy with GitHub Pages

1. Upload `index.html`, `style1.css`, `script1.js`, and `tarantado.jpg` to the root of your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your branch (usually `main`) and the `/ (root)` folder, then save.
5. After GitHub Pages finishes deploying, open the URL shown in the Pages settings.

## Customization

Update the personal details, project descriptions, links, and contact information in `index1.html`. The main color variables are near the top of `style1.css`.
